- shape-cpu: mask pictures and masks interned once with the paths; each frame records the masked groups and renders them: the mask drawn over each group's pop region at the pop, its value in double
- blend2d: immediate mode, no build step; a masked group is a layer multiplied (BL_COMP_OP_DST_IN) by a mask layer drawn at its end; a luminance mask is converted by hand (Blend2D has no luminance filter): a check of the layer code only
- skia: SkCanvas drawPath and saveLayer, paths and shaders built once; a masked group's layer is multiplied by a mask layer (blend mode kDstIn) drawn at its end; a luminance mask through SkLumaColorFilter, Rec. 709 by probe
- Alpha-mask groups are checked against both references, each by a layer multiplied by the mask's layer (Blend2D and Skia, DST_IN); luminance masks against Skia, whose luma filter uses Rec. 709's coefficients (found by probe, refs/probe-skia-luma.cpp), which are the set the scene's luminance masks name.
- Blend2D has no luma filter: its driver converts the mask's layer by hand with the same numbers, so for the luminance masks it checks the layer code only, not a luminance.
- The bound cannot tell Rec. 709's coefficients from W3C's (at most a twentieth of an 8-bit level apart); the probe does.  The control drops every sixteenth drawable of the groups' contents, never a mask's picture.
